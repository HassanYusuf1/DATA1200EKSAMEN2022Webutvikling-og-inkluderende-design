## 📋 Prosjektoversikt

Dette prosjektet er en responsiv nettside for "Guttas Vertshus", et lokale for arrangementer og café beliggende i Finnsnes, Norge. Nettsiden fungerer som en digital plattform for kunder som ønsker å utforske lokalets tjenester, meny og gjøre reservasjoner.

### 🌟 Funksjoner

- **Responsivt Design**: Optimalisert for desktop, nettbrett og mobilenheter
- **Bookingsystem**: Enkelt skjema for å be om reservasjon av lokalet
- **Menyvisning**: Presentasjon av caféens tilbud med detaljert informasjon og bilder
- **Stedsinformasjon**: Interaktiv kartintegrasjon og kontaktdetaljer
- **Tilgjengelighet**: Bygget med universelle designprinsipper for alle brukere

## 🔍 Tilgjengelighetsfunksjoner

<div align="right">
  <img src="https://via.placeholder.com/150x150/ffffff/6e7f80?text=A11Y" alt="Accessibility Icon" style="border-radius: 10px; float: right; margin: 0 0 10px 20px;">
</div>

Nettsiden er designet med universelle designprinsipper i tankene:

- ♿ **Semantisk HTML-struktur** for bedre skjermleserkompatibilitet
- 👁️ **Riktige kontrastforhold** for optimal lesbarhet av tekst
- ⌨️ **Tastaturnavigasjonsstøtte** med tabindex-attributter
- 🖼️ **Alternativ tekst** for alle bilder og grafiske elementer
- 📱 **Responsivt design** for alle enhetsstørrelser
- 📝 **Klar, lesbar typografi** med passende størrelse og linjeavstand

## 📊 Testing og validering

Nettsiden har blitt testet ved hjelp av [Web Accessibility Evaluation Tool (WAVE)](https://wave.webaim.org/) for å sikre samsvar med tilgjengelighetsstandarder. Alle feil har blitt adressert og kun mindre advarsler gjenstår.
