## 📋 Project Overview

This project is a responsive website for **Guttas Vertshus**, an event venue and café located in Finnsnes, Norway. The website serves as a digital platform for customers to explore the venue's services, view the menu, and make bookings.

---

## 🌟 Features

- **Responsive Design**: Optimized for desktops, tablets, and mobile devices  
- **Booking System**: Simple booking form for event inquiries  
- **Menu Display**: Showcase of the café's offerings with detailed descriptions and images  
- **Location Information**: Interactive map and contact details  
- **Accessibility**: Built using universal design principles for all users

---

## 🧰 Tech Stack

- **HTML5** – Semantic markup for enhanced accessibility  
- **CSS3** – Responsive design with media queries  
- **JavaScript** – Interactive elements and functionality

---

## 📱 Pages

1. **Welcome (index.html)** – Introduction to the venue  
2. **Booking (Booking.html)** – Booking form and venue details  
3. **Menu (meny.html)** – Overview of food and beverage offerings  
4. **Information (aktuellinformasjon.html)** – News and updates  
5. **Accessibility (tilgjenglighet.html)** – Accessibility features and information

---

## ♿ Accessibility

The website is developed with universal design principles in mind:
- Semantic HTML for improved screen reader support
- Proper contrast ratios for readability
- Keyboard navigation enabled with `tabindex` attributes
- Alternative text for all images
- Responsive design for all device sizes
- Clear, readable typography with appropriate font sizes

---

## 🔍 Testing & Validation

The website has been tested using the [WAVE – Web Accessibility Evaluation Tool](https://wave.webaim.org/) to ensure compliance with accessibility standards. All major errors have been resolved, with only a few minor alerts remaining.
