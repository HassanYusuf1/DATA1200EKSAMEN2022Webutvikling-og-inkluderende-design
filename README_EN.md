## 📋 Project Overview

This project is a responsive website for **Guttas Vertshus**, an event venue and café located in Finnsnes, Norway. The website serves as a digital platform for customers to explore the venue's services, view the menu, and make bookings.

---

## 🌟 Features

- **Responsive Design**: Optimized for desktops, tablets, and mobile devices  
- **Booking System**: Simple booking form for event inquiries  
- **Menu Display**: Showcase of the café's offerings with detailed descriptions and images
