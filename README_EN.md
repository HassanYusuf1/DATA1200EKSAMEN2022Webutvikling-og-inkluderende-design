## 📋 Project Overview

This project is a responsive website for "Guttas Vertshus," an event venue and café located in Finnsnes, Norway. The website serves as a digital platform for customers to explore the venue's services, menu, and to make bookings.

### 🌟 Features

- **Responsive Design**: Optimized for desktop, tablet, and mobile devices
- **Booking System**: Simple form to request event bookings 
- **Menu Display**: Showcase of café's offerings with detailed information and images
- **Location Information**: Interactive map integration and contact details
- **Accessibility**: Built with universal design principles for all users

## 🧰 Tech Stack

- **HTML5**: Semantic markup for better accessibility
- **CSS3**: Responsive design with media queries
- **JavaScript**: Interactive elements and functionality

## 📱 Pages

1. **Welcome (index.html)**: Introduction to the venue
2. **Booking (Booking.html)**: Booking form and venue information
3. **Menu (meny.html)**: Food and beverage offerings
4. **Information (aktuellinformasjon.html)**: Current topics and news
5. **Accessibility (tilgjenglighet.html)**: Information about accessibility implementation

## 🔍 Accessibility Features

The website has been designed with universal design principles in mind:

- Semantic HTML structure for better screen reader compatibility
- Proper contrast ratios for text readability
- Keyboard navigation support with tabindex attributes
- Alternative text for all images
- Responsive design for all device sizes
- Clear, readable typography with appropriate sizing

## 📊 Testing & Validation

The website has been tested using the [Web Accessibility Evaluation Tool (WAVE)](https://wave.webaim.org/) to ensure compliance with accessibility standards. All errors have been addressed and only minor alerts remain.
